# Variance and Flux Analysis changelog

## Included in SuiteSkills 1.0.0

Component version: 1.0.1. Source version: 1.0.1.

Use report totals as the financial reconciliation basis. If the report exposes summary lines only, obtain account-level detail from a metadata-qualified transactionaccountingline path with explicit transaction-line join keys, posting filters and one verified accounting book. Reconcile its account sums to comparable report totals before explaining drivers. Preserve period/entity/currency scope, revenue-versus-expense direction, and any unresolved residual; accessible detail does not prove a cause.
