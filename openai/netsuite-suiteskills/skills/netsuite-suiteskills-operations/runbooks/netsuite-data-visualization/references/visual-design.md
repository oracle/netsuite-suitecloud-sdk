# Fixed Redwood-style presentation

The reviewed renderer restores the original supplied design's Ocean #264759 header, #F1EFED page, #FBF9F8 flat portlets, 26px title, 14px panel headings, 1240px canvas, 16px gutters and 1.35:1 desktop chart grid. At 900px and below charts stack; all-KPI views use four columns, then two, with quiet dividers. Exact values, units, source status and limitations stay visible. Compact axis and bar labels are rounded for readability; tooltips and the detail table retain the exact supplied numeric values.

Series order: #245D63, #D7790F, #31A09C, #4E4137, #699E61, #B47282, #83401E, #9E7FCC, #A88E00, #58316E, #5999B5, #317A45. Explicit labels and line dash patterns supplement color. Headings and numbers use locally installed Oracle Sans Tab/Oracle Sans when available, then system fallbacks. No font, template, vendor JavaScript or texture binaries from the original submission are bundled. This preserves the visual language without claiming pixel identity, original font availability or rights clearance.

Layout is fixed by reviewed assets. Source fields cannot provide CSS, HTML, callbacks, URLs or scripts. Charts and KPI panels share one typed row population; a KPI-only strip requires a single complete supplied aggregate row. A multi-dataset dashboard mixing different source grains is outside this version's contract. Use separately scoped views rather than duplicate rows or invent totals. See [chart contract](chart-contract.md) for supported chart types and bounds; Sankey is not implemented.

HTML has local search, first-grain filtering, sorting and row details. No export buttons or refresh callbacks are shown. PDF and PowerPoint are generated only on request through the secured export engine; every chart derives from the same validated model. PowerPoint uses the reviewed minimal Ocean theme and captured chart panels rather than the legacy corporate template/export kit. Recipient-app rendering remains a separate qualification.
