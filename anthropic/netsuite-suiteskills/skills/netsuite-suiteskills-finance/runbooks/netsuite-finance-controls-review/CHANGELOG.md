# Finance Controls Review changelog

## Included in SuiteSkills 1.0.0

Component version: 1.0.1. Source version: 1.0.1.

For an ordinary operational review, proceed with the stated defaults when no supplied policy supersedes them and label the basis; do not block unrelated checks on a materiality question. In an audit context, threshold-dependent conclusions need the applicable policy; return independent observations while that input is unavailable. To test preparer/approver overlap, obtain actual creator/preparer and approval-event actor IDs for the same transaction using verified record/audit evidence. Compare IDs after validating event meaning; lastModifiedBy is not an approver. Missing approval evidence means not verified, not no overlap.
