# Service-report source index

For report modes, see the [workflow index](../../workflows/service-reports/index.md#choose-the-workflow).

## Source policy

For each applicable report workflow, read its linked skill references and open and check the relevant external documentation URLs indexed here before relying on their guidance.  This rule applies to service-report work; it does not change reference rules for other FSM workflows.

Use only the exact indexed URLs, including the identified entries in the linked configuration index. Do not search for, follow links to, or cite other external pages unless the user explicitly asks. Public documentation access does not authorize additional NetSuite account access. If a linked page is unavailable or redirects to an unlisted URL, record it as unchecked and state which guidance remains unverified. Keep source URLs, check date, checked/unchecked status, and affected guidance in the report handoff.
