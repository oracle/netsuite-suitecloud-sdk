# VS Code extension guidance

## Ownership

Edit TypeScript under `src/`; `dist/` is generated by compilation.
`src/suitecloud.ts` owns activation and command registration.
Keep registered command IDs consistent with `package.json` contributions,
menus, keybindings, views, and walkthroughs.
Command implementations live in `src/commands/`, with services in `src/service/`.
Keep `messages.json`, `TranslationKeys.ts`, and `VSTranslationService.ts` aligned
when changing user-facing text or translation keys.

The Developer Assistant control panel lives in `src/controlPanel/`, including
its protocol, view, and workflow code. Cline integration under
`src/controlPanel/developerAssistant/cline/` is intentional product behavior;
preserve its compatibility checks and configuration contracts.

## Dependencies and compatibility

This package is outside the root npm workspaces and has its own
`package-lock.json`. Manage its dependencies from this package rather than
assuming root workspace installation includes them.
The extension consumes `@oracle/suitecloud-cli` as a dependency.
Preserve the existing extension-host APIs and TypeScript compilation settings.

There is an existing minimum-version discrepancy: the [README](README.md) lists
VS Code 1.131.0 or higher, while `package.json` declares `engines.vscode` as
`^1.106.0`. Flag this when relevant; resolve it only in a separately scoped change.

## Verification and packaging

With this package's dependencies installed, compile from the repository root:

```sh
npm --prefix packages/vscode-extension run compile
node packages/vscode-extension/dist/test/runTest.js
```

Compilation checks TypeScript. The second command runs extension-host tests via
`@vscode/test-electron` and can download and launch VS Code.
`src/test/suite/index.ts` explicitly lists test files; add new suites there.
Report compilation and extension-host results separately.
Keep contributor guidance excluded through `.vscodeignore`; inspect the extension
inventory with `vsce ls` from this package when that tool is available.
