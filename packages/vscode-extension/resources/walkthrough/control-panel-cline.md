# Connect Cline

Cline is an optional AI coding assistant that uses SuiteCloud Proxy to connect to SuiteCloud Developer Assistant. Select **Configure** to set the base URL, model ID, and API key in Cline's global configuration.

1. Install Cline if the **Cline extension** section shows **Not installed**.
2. Start SuiteCloud Proxy.
3. In the **Cline extension** section, select **Configure**, then confirm the change.
4. If prompted, select **Restart extensions** to finish configuring Cline.
5. Select **Open Cline** to begin using Developer Assistant.

Cline is ready when both statuses show **Installed** and **Configured**.

You can also use another OpenAI-compatible coding tool. Expand **API provider configuration** to view the required values. To copy a full API key, stop SuiteCloud Proxy, then select **Rotate API key**.
