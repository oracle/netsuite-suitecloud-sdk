# Connect Cline

Cline is an optional AI coding interface. **Apply settings** configures it to send requests through the SuiteCloud local service.

1. Install Cline if the panel shows **Cline not installed**.
2. Start the SuiteCloud local service.
3. In **Cline integration**, select **Apply settings** and confirm the change.
4. If prompted, restart the VS Code extensions so Cline loads the new configuration.
5. Select **Open Cline Chat** to begin using Developer Assistant.

Setup is complete when the Cline status shows **ready** and the message says **Cline installed and configured**.

You can use another OpenAI-compatible coding tool instead. Expand **API provider settings** and copy the displayed provider values into that tool.
