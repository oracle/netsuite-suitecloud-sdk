# Connect with Cline

In **Cline Integration**, use **Update Cline Config** after proxy is running.

What to verify:
- Compatibility is shown as `Compatible` (or a clear message is shown when not compatible).
- Cline provider is set to `OpenAI Compatible` with the local proxy base URL.

Then use **Open Cline Chat** to start prompting against the local SuiteCloud proxy.
