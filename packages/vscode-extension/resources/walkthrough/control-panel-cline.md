# Connect Cline

Cline is an optional AI coding assistant. It uses the SuiteCloud Proxy to connect to SuiteCloud Developer Assistant. **Configure** writes the Base URL, Model ID, and API key to Cline's global configuration.

1. Install Cline if the **Cline Extension** card shows **Not Installed**.
2. Start the SuiteCloud Proxy.
3. In **Cline Extension**, select **Configure** and confirm the change.
4. If prompted, restart the VS Code extensions so Cline loads the new configuration.
5. Select **Open Cline Chat** to begin using Developer Assistant.

Setup is complete when the card shows **Installed** and **Configured**.

You can use another OpenAI-compatible coding tool instead. Expand **API provider configuration** to find the required values. To copy a full API key, stop the SuiteCloud Proxy and rotate the key.
