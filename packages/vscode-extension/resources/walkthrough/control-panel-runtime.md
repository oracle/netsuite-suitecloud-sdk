# Start the SuiteCloud Proxy

The SuiteCloud Proxy is required by SuiteCloud Developer Assistant. It runs on your computer and connects your AI coding tool to Developer Assistant using the Auth ID and API key you selected.

1. Keep the default **Local port** (`8181`) unless another application is already using it.
2. Select **Start** and review the notice about AI-generated content.
3. Wait for the status beside **SuiteCloud Proxy** to change to **running**.

While the SuiteCloud Proxy is running, the account, port, and API key are locked to prevent accidental connection changes. Select **Stop** before editing them.

If the SuiteCloud Proxy does not start, select **See Proxy logs** for the detailed error and suggested next step.
