# Start SuiteCloud Proxy

SuiteCloud Developer Assistant requires SuiteCloud Proxy. It runs on your computer and connects your AI coding tool to Developer Assistant using the auth ID and API key you selected.

1. Leave **Local port** set to 8181 unless another application is using it.
2. Select **Start**, then review the notice about AI-generated content.
3. Wait until SuiteCloud Proxy status changes to **running**.

While SuiteCloud Proxy is running, you cannot change the auth ID, local port, or API key. Select **Stop** before changing these settings.

If SuiteCloud Proxy does not start, select **See SuiteCloud Proxy logs** to view the detailed error and suggested next step.
