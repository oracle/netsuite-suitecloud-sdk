# Start the local service

The local service connects your AI coding tool to SuiteCloud Developer Assistant. It runs on your computer and uses the Auth ID and API key you selected.

1. Keep the default **Local port** (`8181`) unless another application is already using it.
2. Select **Start** and review the AI-generated-content notice.
3. Wait for the status beside **Local service** to change to **running**.

While the service is running, the account, port, and API key are locked to prevent accidental connection changes. Select **Stop** before editing them.

If the service does not start, select **See service logs** for the detailed error and suggested next step.
