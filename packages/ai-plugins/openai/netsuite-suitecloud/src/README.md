# NetSuite SuiteCloud

This plug-in is compatible with ChatGPT and Codex. It includes skills that support key areas of SuiteCloud development, such as SuiteScript, SDF, UIF SPAs, security, permissions, documentation, modernization, and SAFE Guide best practices. It helps SuiteCloud developers and SuiteApp teams create accurate, secure, and maintainable code and project artifacts.

## Supported Tasks

The following list describes the specific actions the plug-in can perform in your SuiteCloud projects.

- Build and review SuiteScript and SDF solutions using governance, security, performance, and defensive-coding best practices.
- Generate and validate SDF objects, custom roles, permission configurations, and script deployment access.
- Look up NetSuite record types, field IDs, data types, required status, and search capabilities.
- Build and debug UIF SPA applications using @uif-js/core and @uif-js/component API references.
- Upgrade SuiteScript 1.0 and 2.x code to SuiteScript 2.1, including API mappings and behavioral changes.
- Review JavaScript and SuiteScript for OWASP risks and suggest secure implementation patterns.
- Generate SDF project documentation, architecture diagrams, deployment runbooks, and troubleshooting guides.
- Explain, annotate, and review SuiteScript and SDF code to help developers understand NetSuite APIs, governance, security, caching, and SAFE Guide practices.
