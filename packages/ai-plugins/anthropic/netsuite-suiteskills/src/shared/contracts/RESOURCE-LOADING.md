# Loading shared resources

Installed category skills reference their category-local shared README. The publisher generates identical copies from one canonical shared source inside every installed skill; no sibling or plugin-root mount is required. Resolve relative paths from the referring file, not the working directory. Reuse successfully loaded resources while the installed package/session is unchanged. Load the shared baseline and response rules; select further evidence, links, report and visualization references according to the actual task. This is instruction discovery, not another user-facing intake step.

When a reference fails, record the installed plugin identity/version if available, referring file, attempted resolved path and returned error in technical evidence. Inspect the supported installed package layout and try the correctly resolved root path when available. Do not scan unrelated files, change installation or repeatedly retry the same denial.

Distinguish:

- `missing_from_package`: an inspected installed package inventory establishes the file is absent.
- `path_resolution_failed`: the attempted path does not resolve; the file's package presence is not yet established.
- `host_access_unavailable`: the host does not expose or allow the resource.
- `not_checked`: no installed-resource read has established its availability.

A local release ZIP containing the file does not prove the host can read its installed copy. A failed relative lookup does not establish a packaging defect. Do not claim to apply an unread shared revision. Continue independently supported work using accessible instructions and state only the material limitation. Use an accessible fallback only if the selected runbook permits it and all required authorization, disclosure, analyst and export gates can still be satisfied. Report an unmet gate instead of treating a fallback theme as verified shared behavior.

## Installation qualification

After installation or a host/package change, a host test should start from an actual category SKILL.md, open its referenced category-local shared README, then the baseline, concise response rules, evidence and links. For a visual request also open the design/dashboard references and the selected renderer entrypoint. Retain exact resolved paths and results. A package-local reference test is useful but does not replace this host test.

Do not repeatedly perform this diagnostic sequence in ordinary answers. The generated copies support isolated category folders. Each copy must match the canonical resource map. Never edit a generated copy independently or substitute runbook-local domain contracts for common guidance. If a category copy is unavailable, report the exact missing path and installation failure.
