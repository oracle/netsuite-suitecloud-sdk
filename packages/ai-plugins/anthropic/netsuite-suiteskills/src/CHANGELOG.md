# SuiteSkills changelog

## 1.0.0 — Initial release

SuiteSkills provides role-based NetSuite workflows across Customers & Sales, Finance, Onboarding, Operations and Workforce.

- Provides guided onboarding and workflows that use NetSuite data or user-supplied evidence, subject to available tools, account features and role permissions.
- Includes analysis, drafts, recommendations and supported actions with workflow-specific validation and authorization safeguards. Bank Reconciliation Prioritization remains read-only.
- Provides visualization and file output according to host capabilities, execution requirements, dependencies and limitations. See [security notes](SECURITY-CHANGELOG.md), [visualization notes](VISUALIZER-CHANGELOG.md) and [support limits](README.md#prerequisites-and-limitations).
