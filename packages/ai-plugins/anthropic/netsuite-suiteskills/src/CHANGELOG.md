# SuiteSkills changelog

## 1.0.0 - Initial-release documentation

This entry describes the proposed 1.0.0 scope. Release authorization requires recorded component redistribution clearance and engineering acceptance of the final packages. Security approval covers the security review; it does not establish redistribution rights or installed-runtime qualification.

- Includes five skills: Customers & Sales, Finance, Onboarding, Operations, and Workforce, with 48 business runbooks.
- Provides guided onboarding and workflows that use NetSuite data or user-supplied evidence, subject to available tools, account features, and role permissions.
- Includes analysis, drafts, recommendations, and supported actions with workflow-specific validation and authorization safeguards. Bank Reconciliation Prioritization remains read-only.
- Provides visualization and file output according to the host capabilities, execution requirements, dependencies, and limitations described in the README.
- Uses The Universal Permissive License (UPL), Version 1.0 as the selected first-party license. Preserve component-specific licenses and required notices.
- Security review and approval are complete.
