# Vendor Optimization changelog

## Included in SuiteSkills 1.0.0

Component version: 1.0.1. Source version: 1.0.1.

Build vendor comparisons from verified purchase-line/receipt facts at a stated grain. Do not rely on an unverified itemvendor join: establish the actual relationship or use transaction-based vendor evidence with its narrower coverage. The packaged vendor-comparison candidate query is a metadata-review starting point, not a current-account guarantee. Use equivalent factual text tables when the widget is absent; preserve the same ranking, exclusions and uncertainty in every format.
