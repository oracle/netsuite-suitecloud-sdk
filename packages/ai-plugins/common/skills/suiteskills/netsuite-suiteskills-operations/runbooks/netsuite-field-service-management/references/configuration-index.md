# FSM configuration documentation index

For local guidance, start with [effective configuration](configuration.md#effective-configuration), [resource section routes](fsm-mobile-resource-properties-reference.md#section-routes), or [element section routes](fsm-mobile-blocks-reference.md#section-routes). When you need more detail, choose an Oracle page for the configuration symptom or change you are investigating. Read the paired pages when a question crosses a boundary. Check effective account configuration before relying on a documented default or changing a setting.
