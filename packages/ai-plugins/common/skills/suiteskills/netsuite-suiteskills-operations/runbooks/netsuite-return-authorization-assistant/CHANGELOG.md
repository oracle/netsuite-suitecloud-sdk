# Return Authorization Assistant changelog

## Included in SuiteSkills 1.0.0

Component version: 1.0.0. Source version: unknown.

Use to review customer return authorizations (RMAs), linked receipt, credit and refund evidence, refund readiness, or scoped return reports; draft linked or standalone return proposals in chat. Excludes creating or changing records, return approval or receipt, credits, refunds, and replacement orders.
