# Item Purchasing History changelog

## Included in SuiteSkills 1.0.0

Component version: 0.1.0. Source version: 0.1.0.

Treat underscores, percent signs and apostrophes in item names as literal text when compiling the packaged lookup; they do not authorize wildcard matching. If a bill lacks a document number, display its verified type and internal ID (for example “Vendor bill 123”) and a supported record link rather than a blank label. Preserve the existing purchase-line and receipt-pair grain and sampled-history limitations.
