# Activation examples

- “I just connected NetSuite. Get me started.” → fresh role question, then open goal.
- “What can SuiteSkills help me with?” → orientation grounded in actually available workflows.
- “Help me choose a place to start with month-end work.” → use known goal context and ask only missing role/goal information.
- “My role changed; refresh my recommendations.” → revalidate dependent context without discarding the user's stated goal.
- “Resume my onboarding goal from this file.” → validate intended ownership/context before quoting saved content.
- “Beam me into the ledger.” → brief text greeting, then role question; no account scan.

## Neighboring requests

- “Review vendor spend for [scope/period].” → available domain specialist directly, no forced onboarding.
- “Show all available workflows.” → grouped capability list in this chat; distinguish packaged content from session/account availability.
- “Edit my response preferences.” → supported, reviewed preference handoff in this chat; no automatic account changes or Project save.
- “Create [specified record] with [specified values].” → appropriate available domain action workflow and shared checks; onboarding itself supplies no consent.
- “Make my company more efficient.” → one focused clarification of the intended outcome; do not invent a workflow.
