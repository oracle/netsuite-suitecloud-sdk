# Labor Cost Advisor changelog

## Included in SuiteSkills 1.0.0

Component version: 1.0.0. Source version: unknown.

Check the actual report catalog/capability and payroll prerequisites before running labor reports; -334/-335 are historical candidates, not guaranteed report identities. If payroll reports are unavailable, use a verified income-statement/GL salary-and-wage account mapping for a clearly labeled “GL salary expense versus revenue approximation.” Record included/excluded accounts, book, period, entity and currency. It is not total payroll cost, tax/deduction analysis or a reconciliation of the unavailable reports. With missing account mapping or revenue basis, withhold the ratio. Prefer useful text when the dashboard is unavailable or not requested.
