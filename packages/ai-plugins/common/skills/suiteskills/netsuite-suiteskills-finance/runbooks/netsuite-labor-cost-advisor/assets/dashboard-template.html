Read the model correctly

This local model does not change NetSuite payroll. Revenue after labor is before other costs, not profit.

Modeled labor = fixed unmodeled labor + adjusted setup item amounts. Labor / revenue = modeled labor ÷ fixed reported revenue. The source period, mapping, and employee completeness appear above.
