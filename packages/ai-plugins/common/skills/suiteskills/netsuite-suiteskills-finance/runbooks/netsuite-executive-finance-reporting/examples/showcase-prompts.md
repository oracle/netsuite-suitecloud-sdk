# Showcase Prompts - Executive financial reporting

1. Build a CFO-ready summary for [period] using only named upstream finance-skill results and include a provenance table for every headline metric.
2. Assemble a board package from completed financial-statement, variance, cash, and close-status analyses for [subsidiary].
3. Create an executive narrative for [period] but exclude any headline figure whose upstream result is partial, unverified, or fails a tie-out.
4. Prepare a one-page management summary that distinguishes recurring trends from one-time items and names an owner and date for each action.
5. Prepare the final executive package for the team and, if no delivery connector is available, return the package with delivery clearly marked as blocked rather than claiming it was sent.
