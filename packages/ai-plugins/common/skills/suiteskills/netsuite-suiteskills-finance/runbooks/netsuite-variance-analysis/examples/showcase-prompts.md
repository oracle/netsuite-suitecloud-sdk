# Showcase Prompts - Variance and flux analysis

1. Compare actual results with budget for [period] and stop with a clear evidence boundary if no accessible budget source exists.
2. Compare [period] with the prior period for [subsidiary], apply materiality, and reconcile all quantified drivers to the total variance.
3. Explain the largest revenue and COGS variances using price and volume only where the supporting data actually verifies those drivers.
4. Review operating-expense variances across [period range], separating recurring, timing, one-time, and reclassification effects.
5. Analyze a report where detail signs appear opposite to the parent total and keep the variance at the verified summary level unless sign normalization can be proven.
