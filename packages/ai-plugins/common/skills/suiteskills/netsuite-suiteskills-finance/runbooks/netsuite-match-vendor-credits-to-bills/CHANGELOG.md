# Match Vendor Credits to Bills changelog

## Included in SuiteSkills 1.0.0

Component version: 1.0.2. Source version: 1.0.2.

Verify the available vendor-credit amount before proposing allocations. Use an authoritative AP aging/open-credit source or schema-qualified application links, including NextTransactionLineLink only when its direction, link types, currency and completeness are established. Reconcile original credit less all relevant applications to a supported current unused amount. For historical scope use applications through that cutoff. A candidate credit with unknown unused balance may be listed but must not be allocated. Apply the root shared link contract consistently with Vendor Spend Analysis.
