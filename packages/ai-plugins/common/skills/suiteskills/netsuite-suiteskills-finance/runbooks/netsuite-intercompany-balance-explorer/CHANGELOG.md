# Intercompany Balance Explorer changelog

## Included in SuiteSkills 1.0.0

Component version: 1.1.3. Source version: 1.1.3.

Review intercompany exposure, subsidiary-pair differences and journal activity for a date range or as-of date. Use for read-only intercompany investigation with verified non-overlapping subsidiaries and comparable currency, book and posting bases; posting, approval and elimination actions require a separate workflow.

Separate sales/purchase matching, posted elimination, mapped-account balance and intercompany-JE source populations. Keep pending entries explicitly outside posted balance and tie-out calculations. Require explicit returned evidence before linking a prior-period JE to a current exception.
