# Showcase Prompts - Invoice collections

1. Summarize receivables for [subsidiary] as of [date] and show aging columns without inventing bucket labels when the connector does not return them.
2. Build a prioritized collections queue using only the payment, dispute, credit, fulfillment, and exposure factors that are actually verified for each customer.
3. Quantify invoice-to-payment linkage coverage for [period] and explain which payment-behavior conclusions cannot be supported when links are sparse.
4. Separate receivables with no verified customer/entity into an unattributed-AR bucket before producing customer-level exposure and collection priorities.
5. Draft outreach for the selected overdue invoices and, if no mail capability is available, hold the drafts for review and mark delivery as blocked.
