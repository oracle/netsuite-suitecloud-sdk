# Standard Tools reference

The bundled standard-tools.json is the Alpha 11 historical SuiteApp 2.2.0 schema catalog. Use current callable schemas for an operation, reusing current discovery when applicable. The catalog is illustrative historical evidence, not an exclusive tool list. Missing entries do not prohibit discovering another supported capability. The per-runbook tool_plan is a suggested branch-dependent mapping, not a required call sequence or account qualification.

Use focused record reads, an appropriate existing search/report, or metadata-supported bounded SuiteQL. Use a submitted query helper only with its own submitted resources and contract. This candidate carries no legacy business query registry. For a requested action, establish its scope, authorization, supported tool schema and business prerequisites; execute only when these are satisfied and verify the resulting state. Keep proposals distinct from completed actions. Tool presence never grants permission.
